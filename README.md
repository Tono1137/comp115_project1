# Python turtle code that draws the solar system from the game "Outer Wilds"

Each function draws a different celestial body, starting with the furthest from the sun.


"make_star" generates stars with random positions and colors.
Function input is the amount of stars to generate

"interloper" is the comet at the top

"bramble" is the black sphere with ice

"ice" generates ice blocks used in "bramble" and "interloper"

"deep" is the green planet with the orbital cannon

"hollow" is the purple planet

"hearth" is the green planet with rivers and a moon

"twins" is the pair of sand planets

"sun" is the sun


"starcolor" is a list containing the possible colors "make_star" can choose from

coordinates and scale of planets can be edited within each function

(the scale of "deep" cannot be changed however, which is due to the latitudinal lines
being done manually instead of generated based on radius of the planet)
